## AghathNX v1.0 — Agatha das pedras raras 💎

The first AghathNX build. It is based on **Fritchii v5.8.4** by Frizti, so everything Fritchii
v5.8.4 does (Ocarina of Time performance, DLSS per game, the Saves window and the rest) is here.

What's new in AghathNX:

- **New name and gem icon.**
- **Its own data folder** (`%APPDATA%\aghathnx`). On the first launch it offers to copy your
  saves, settings and mods from Fritchii, Eden, Lichii, yuzu, suyu, sudachi or citron. The old
  folder is never changed.
- **No automatic updates for now.** New versions are posted on the AghathNX GitHub page.

AghathNX is free software (GPL-3.0), built on the work of Fritchii, Lichii, Eden and yuzu.
